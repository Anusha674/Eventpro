# EventPro

EventPro is a Flask-based Event Management System that allows users to browse events, book tickets, make payments, and view booking QR codes. It also includes an admin panel for managing events, venues, organizers, staff, bookings, payments, and reports.

## Features

- User registration and login
- Browse available events
- View event details
- Book event tickets
- Payment tracking
- QR code generation for bookings
- Customer dashboard
- Admin dashboard
- Manage events, venues, organizers, and staff
- View bookings and payment reports
- Contact page

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Flask-Mail
- QRCode
- Pillow
